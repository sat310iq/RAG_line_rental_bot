# テスト戦略ガイド（2026-02-07）

## 目的
RAGの回答ロジック検証において、状況に応じた最適なテスト手段を選べるようにする。

## 状況別の推奨対応

| 状況 | 対応 |
| --- | --- |
| テストを自動化して継続実行したい | pytest + LLMモック |
| 今すぐ結果を確認したい（新実装の初期確認） | CLI手動確認で十分 |
| LLMの出力が変動して困っている | モック or 出力差分だけ見る |
| スコア閾値・CSV/PDF優先など分岐条件を明確に保証したい | pytestで実施する |

## 補足
- pytestは分岐条件やフォールバックの再現性を高く保てるため、CI向き。
- CLI手動確認は実装直後のスモークテストに適する。
- LLM出力の揺れが影響する場合は、モックや差分観測でロジックのみ検証する。
