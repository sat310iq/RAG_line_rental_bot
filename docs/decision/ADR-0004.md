# ADR-0004: 評価データセットのCSV暫定修正（実ファイル名への置換）

## ステータス

**暫定措置**（期限: 3ヶ月以内）

## 背景

INC-EVAL-0001の修正過程において、`eval_questions.csv`の`relevant_doc_ids`列を実ファイル名（`グランマーレ大分空港契約書.pdf p5`）に置換する暫定修正を実施した。

## 決定

### 暫定措置

以下の2行を実ファイル名に置換：

1. **Q002**: `contract.pdf p5` → `グランマーレ大分空港契約書.pdf p5`
2. **Q004**: `contract.pdf p12` → `グランマーレ大分空港契約書.pdf p12`

### 理由

- ID Normalization Success Rateを即座に100%に改善する必要があった
- `eval_id_mapper.py`のPDFマッピング機能は強化済みだが、評価の即時改善が優先

## 長期方針

**Mapper中心アプローチ**を採用：

- `eval_questions.csv`は**論理ID**（`contract.pdf p5`）を保持
- `eval_id_mapper.py`で必ず正規化（ファイル名は環境依存）
- これにより、PDFの差し替え、ファイル名変更、複数契約書の追加に対応可能

## 期限と移行計画

**期限**: 3ヶ月以内（2026-05-03まで）

**移行手順**:
1. `eval_id_mapper.py`のPDFマッピング機能が完全に安定化
2. 複数契約書への対応が完了
3. `eval_questions.csv`を論理IDに戻す
4. 評価を実行してID Normalization Success Rate ≥ 0.95を確認

## リスク

- PDFファイル名が変更された場合、評価が壊れる
- 複数契約書を持つ物件が追加された場合、評価が壊れる
- 評価データセットの可搬性が低下
