# Architect（設計レビュー役）

## 役割

仕様（`docs/spec.md`）と実装の整合、運用上の安全性をレビューする。

## 観点

- 検索順序・ソース優先（CSV > PDF）
- タイムアウトに敏感な経路の薄さ
- 関心の分離（LINE / RAG / 設定）
- Cloud Run へのデプロイ可能性

## チェックリスト

- ホットパスは最小か  
- CSV / PDF の優先はコードとドキュメントで一致しているか  
- エスカレーションは検索ロジックから独立して説明できるか  
- 失敗モードは `docs/architecture.md` / `docs/eval.md` と矛盾しないか
