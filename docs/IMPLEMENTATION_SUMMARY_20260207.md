# 実装内容サマリと評価（2026-02-07）

## 目的
CSV優先のRAG挙動を安定化し、誤回答や根拠不一致を抑制しながら、段階的フォールバック（CSV→PDF→問い合わせ）を導入する。

## 主要な実装内容

### 1) 検索・回答の安定化
- **CSV優先の選択**: 再ランキングでCSVを先に並べた後で `top_n` を適用するよう変更し、CSVが落ちる問題を回避。
- **Responderの選択ロジック**: 高信頼度優先の上書きを撤廃し、検索順位を尊重する設計に変更。
- **CSVキーワード優先**: CSVでキーワード一致が1件でもあればスコア閾値をスキップし、確実にCSV回答を返す。

### 2) 出力の重複抑止
- **`render_answer_text()`** を summary優先に変更。summaryが空の場合はitemsでフォールバック。
- **CLIの根拠表示** を items＋citation 表示に統一し、本文の重複を解消。

### 3) キャッシュの健全性
- **KB更新に追従するキャッシュバージョン**を導入。
- `--reset-cache` オプションと `/clear_cache` コマンドで手動クリア可能に。

### 4) CSV→PDF→問い合わせフォールバック
- **スコア付き検索結果**に統一（document + score + source + retriever）。
- **CSV/PDFスコア閾値**を導入し、閾値未満は該当なしと判定。
- **フォールバック文言**を `config.py` と `.env` に切り出し。
- **分岐ログ**で「CSV閾値未満→PDF→該当なし」を追跡可能に。

### 5) CSVの整備
- `faq_kb.csv` の列ズレを是正、項目の追加・削除を反映。
- `契約_解約` を削除、`設備_故障` にエアコン/給湯器/換気扇などを追加。
- `ペット飼育の可否` に犬/猫/イヌ/ネコを追加。

### 6) 再インデックスの修正
- `reindex_vector_db.py` で既存コレクションを **明示的に削除**して再作成するよう変更。

## 変更ファイル（抜粋）
- `src/rag_answerer.py`（CSV優先・キーワード上書き・フォールバック）
- `src/vector_store_manager.py`（スコア付き検索）
- `src/config.py`（閾値・固定文言の設定）
- `src/query_cache.py`（KBバージョンでのキャッシュ無効化）
- `src/rental_qa_chat.py`（根拠表示・キャッシュクリア）
- `scripts/reindex_vector_db.py`（コレクション削除）
- `data/faq_kb.csv`（キーワード追加/削除/整形）
- `.env`, `env.example`（閾値・固定文言）

## 評価

### 良い点
- **CSV優先**が実質的に保証され、誤回答（喫煙など）の混入が大幅に減少。
- **段階的フォールバック**のログが明確になり、運用・調査が容易。
- **重複表示の解消**によりユーザ体験が改善。
- **キャッシュの健全性**が向上し、KB更新の反映漏れが解消。

### リスク/注意点
- **スコア閾値の調整**は運用で継続的なチューニングが必要。
- **CSVキーワード一致の強制採用**は、キーワードの粒度設計が甘い場合に誤爆の可能性あり。
- **スコア算定**は現状の簡易実装のため、厳密な関連度とは一致しない可能性がある。

### 推奨の次アクション
- CSVキーワードの粒度を継続的に改善（曖昧語の整理）。
- CSV/PDF閾値の検証データセットを整備し、定期的に調整。
- スコア計算を統一指標に寄せる（Vector/BM25の重み調整）。
