### 読み方

- **期待ふるまい**: データセット作成時の意図。自動採点ではなく、人手レビュー用の基準です。
- **ローカル:主な取得ソース**: `retrieved_sources` 先頭数件の `source_type` と `source_id`（snippet は省略）。
- **ローカル:fallback=true**: 根拠なし、またはフォールバック文言が本文に含まれる場合（`run_eval.py` 定義）。
- **Cloud 列**: 同じ手順で Cloud 上の JSONL を取ったら、`jq` やスプレッドシートに貼って差分確認する。
