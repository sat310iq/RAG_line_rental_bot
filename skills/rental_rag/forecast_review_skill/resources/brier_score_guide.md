# Brier Score 計算ガイド

## 計算式

予測確率を p（0〜1）、結果を o（発生=1、未発生=0）とする。

Brier Score = (p - o)²

## 解釈

| スコア | 評価 |
|---|---|
| 0.00 | 完璧（確率1.0で発生、または確率0.0で未発生） |
| 0.25 | 基準（確率50%で予測した場合の期待値） |
| 0.50以上 | 悪い（ランダム予測より劣る） |

## 計算例

| 予測確率 | 結果 | Brier Score | 評価 |
|---|---|---|---|
| 70%（0.7） | 発生（1） | (0.7-1)² = 0.09 | 良い |
| 70%（0.7） | 未発生（0） | (0.7-0)² = 0.49 | 悪い |
| 50%（0.5） | 発生（1） | (0.5-1)² = 0.25 | 基準 |
| 50%（0.5） | 未発生（0） | (0.5-0)² = 0.25 | 基準 |

## 累積スコアの見方

4回以上の累積平均で判断する。

| 累積平均 | 判断 |
|---|---|
| ≤ 0.15 | 優秀 |
| 0.15〜0.20 | 良好 |
| 0.20〜0.25 | 基準レベル |
| ≥ 0.25 | 要改善（バイアス特定が必要） |

## アンチパターン

| パターン | 症状 | 対処 |
|---|---|---|
| アンカリング | 施策後も確率が変わらない | 反証サーチを実施する |
| 過剰反応 | 1回の結果で±20%以上変動する | 調整幅を±15%以内に抑える |
| 確率の丸め込み | 常に50%/70%/90%など切りの良い数字 | 1%単位で記録する |
