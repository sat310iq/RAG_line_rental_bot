# 予測タスクテンプレート

新しい予測タスクを追加するときは以下のフォーマットを使う。

---

## PT-NNN: （予測の問い）

**登録日**: YYYY-MM-DD
**採点予定**: 次回eval実行後

### 予測

| 項目 | 内容 |
|---|---|
| 問い | 発生するかしないかで答えられる具体的な問い |
| 予測確率 | XX%（1%単位） |
| 対象指標 | eval_metrics.json または eval/runs/ の具体的なフィールド名 |
| 閾値 | 発生の定義（例: recall@5 ≥ 0.95） |

### Base Rate

（類似の過去施策でどの程度改善したか。なければ「初回のため主観確率」と記載）

### Inside View

（今回固有の要因。施策内容・変更ファイル・影響範囲）

### 反証条件

（この予測が間違っている場合、どんな証拠が存在するか）
