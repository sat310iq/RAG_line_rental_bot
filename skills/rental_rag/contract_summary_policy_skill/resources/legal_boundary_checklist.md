# 適法・違法境界チェックリスト

contract_source_qa_prompt の変更時・回答レビュー時に使用する。
全項目が「適法」であることを確認してからリリースする。

---

## チェック項目

### A. 説明の範囲

| 項目 | 確認内容 | 判定 |
|---|---|---|
| A-1 | 回答が契約書・重説の記載範囲内にとどまっているか | OK / NG |
| A-2 | 契約書外の一般論・慣行を補足していないか | OK / NG |
| A-3 | 根拠箇所（ファイル名・条項）を明示しているか | OK / NG |

### B. 法的評価の不在

| 項目 | 確認内容 | 判定 |
|---|---|---|
| B-1 | 「有利・不利」「リスクが高い」等の評価語を使っていないか | OK / NG |
| B-2 | 「交渉すべき」「削除すべき」等の行動提案をしていないか | OK / NG |
| B-3 | 「弁護士に相談を」等の法的専門家への誘導をしていないか | OK / NG |
| B-4 | 法的効果の有無・程度を判断していないか | OK / NG |

### C. 免責表示

| 項目 | 確認内容 | 判定 |
|---|---|---|
| C-1 | 回答末尾に免責表示が付与されているか | OK / NG |
| C-2 | 免責表示が `prompt_additions.md` の文言と一致しているか | OK / NG |

### D. 個人情報

| 項目 | 確認内容 | 判定 |
|---|---|---|
| D-1 | 氏名・住所・電話番号をAPIリクエストに含めていないか | OK / NG |

---

## 判定基準

- 全項目OK → リリース可
- 1項目でもNG → プロンプト修正後に再チェック
