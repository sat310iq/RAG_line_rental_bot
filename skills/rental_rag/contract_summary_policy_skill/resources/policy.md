# 賃貸契約書AI要約 運用ポリシー v1.0

## 目的

入居者が自分の契約書の内容を理解しやすくすること。
法的判断・アドバイスを提供することではない。

## 法的根拠

### 著作権（翻案権）

管理会社が保有・提供する契約書を自社システムで処理する場合、
著作権問題は生じない。第三者の契約書を処理する場合は別途検討が必要。

### 弁護士法72条（非弁行為）

以下の3点を満たす限り、弁護士法72条に違反しない。
1. 条項の内容を機械的に説明・引用するにとどまる
2. 個別の法的リスクの有無を評価しない
3. 具体的な修正案・交渉の提案をしない

### 個人情報保護法

契約書に含まれる氏名・住所・電話番号等の個人情報はAPIに送信しない。
（将来対応: 送信前マスキング処理）

## 許可する回答内容

| 種別 | 例 |
|---|---|
| 条項の場所の案内 | 「短期解約違約金については第○条特約④に記載があります」 |
| 条項の平易な説明 | 「2年以内に解約した場合、家賃○ヶ月分を違約金として支払う内容です」 |
| 法律用語の平易な説明 | legal_terms_dict.yaml を使用 |
| 根拠箇所の明示 | 「グランマーレ大分空港契約書.txt より」 |

## 禁止する回答内容

| 種別 | NG例 |
|---|---|
| 法的評価・リスク判断 | 「この条項は借主に不利です」 |
| 法的アドバイス | 「この条項について交渉することをお勧めします」 |
| 修正提案 | 「この条項は削除を求めるべきです」 |
| 契約書外の一般論 | 「一般的に原状回復費用は○万円程度です」 |
| 弁護士への誘導 | 「弁護士に相談すべき内容です」（慎重に） |

## 免責表示

契約書QA回答（is_contract_source_question が True の場合）の末尾に必ず付与する。

```
この回答は契約書・重要事項説明書の記載内容をお伝えするものです。
法的な判断や解釈については、専門家にご相談ください。
```
